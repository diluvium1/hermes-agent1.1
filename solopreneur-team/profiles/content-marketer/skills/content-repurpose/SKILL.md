# Content Repurpose

One good idea should ship everywhere it fits, shaped for each channel — never
copy-paste the same text across platforms.

## Procedure

1. **Take the anchor.** A newsletter issue, blog post, video, or long-form piece
   (from the venture's Drive/Notion, or pasted in).
2. **Read the venture's voice + channels** from the registry.
3. **Generate channel-native variants** for the venture's actual channels, e.g.:
   - Short social posts (hook + payoff, platform-appropriate length)
   - A thread / carousel outline
   - A 2–3 line teaser pointing back to the anchor
   - Reusable snippet for the next newsletter
4. **Keep one idea per variant.** Adapt format, length, and CTA per channel.
5. **Save** variants to the venture's calendar as `Draft` and report the set.

## Output shape

```
♻️ Repurpose: {anchor title} → {venture}
[X/short]   …
[thread]    1/ … 2/ …
[teaser]    …
Saved as drafts to: {calendar}
```

## Rules

- Match channel norms and the venture's brand_voice.
- Don't restate facts you can't verify from the anchor.
